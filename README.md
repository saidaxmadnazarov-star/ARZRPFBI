# FBI Arizona Winslow [14] — RP Portal

Полноценный демонстрационный RP-портал:
- страница входа по логину/паролю;
- сессия пользователя;
- отдельные страницы разделов через навигацию;
- роли `agent` и `admin`;
- админ может создавать аккаунты;
- отдельные разделы: ID, вербовки, проверки госорганизаций, гражданка, полиция/CIU, ЧС вербовок, ЧС ID, новости;
- журнал действий;
- база SQLite.

Демо-аккаунты:
admin / admin123
agent / agent123

Запуск:
npm install
npm start
Открыть http://localhost:3000

Для реального интернет-размещения обязательно заменить SESSION_SECRET, включить HTTPS и хранить пароли в виде безопасных хэшей (bcrypt/argon2), а также настроить резервные копии БД.
